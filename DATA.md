# Data

Image data are not committed to git (they made the repository > 12,800 files). Place them
locally at the paths below; `.gitignore` keeps them out of commits.

| Path | Dataset | Used by |
| --- | --- | --- |
| `<anywhere>/BraTS2021_Training_Data/` | BraTS 2021 Task 1 training set, 1,251 cases, 4 sequences + segmentation. Register at the [BraTS 2021 Synapse page](https://www.synapse.org/#!Synapse:syn27046444) | `scripts/prepare_brats.py` |
| `data/brats2021_cache/` | Generated by `scripts/prepare_brats.py` | 3D training / evaluation |
| `dummy_data/Training`, `dummy_data/Testing` | Kaggle "Brain Tumor MRI Dataset" (glioma / meningioma / notumor / pituitary, 2D JPG). Despite the folder name, this is real data | 2D experiments |
| `data/train/tumor`, `data/train/no_tumor` | 2D tumor / no-tumor JPGs | web app model (`src/train.py`) |
| `data/reference_healthy_brain.png` | Reference image for the app | web app |
| `external/figshare_raw/` | figshare brain tumor dataset (Cheng et al. 2015/2016): 3,064 T1-CE slices, 233 patients, expert tumor masks, labels meningioma / glioma / pituitary. Download the 4 zips from https://figshare.com/articles/dataset/brain_tumor_dataset/1512427 (no registration) | `scripts/prepare_figshare.py` |
| `external/figshare_256.npz`, `external/kaggle_{train,test}_256.npz` | Caches made by `scripts/prepare_figshare.py` and `src/train_seg2d.py` | 2D segmentation model |
| `models/seg2d_best.pth` | 2D segmentation / tumor-type model written by `src/train_seg2d.py` | web app (2D uploads) |

For grading or external validation, UCSF-PDGM provides WHO grade and IDH status for
preoperative diffuse gliomas (Calabrese et al., *Radiology: AI* 2022).

Committed split files in `splits/` define every experiment; do not regenerate them after
experiments start. `splits/2d_duplicates_*.csv` list exact pixel duplicates found by
`scripts/dedupe_2d.py`.

The images are still in older commits; removing them from history needs a history rewrite
(e.g. `git filter-repo`) and a force-push, which is a separate decision.
